# Data Sources

Current collection architecture:

- **Primary method:** web scraping
- **Candidate primary source:** FBref
- **Supplementary/reference source:** Football-Data

Day 1 does not scrape or download data. Day 2 must inspect actual source pages to determine which source supplies every field in the data contract. Before automation, inspect accessibility, applicable terms/policies, applicable robots restrictions, a reasonable request rate, and table/page structure. Do not assume every required field is available from every source.
