# Research Questions

## Main question

How are home advantage, goals, and match statistics associated with win/draw/loss outcomes in the Premier League?

| Research question | Required fields |
| --- | --- |
| RQ1 — Does home advantage exist in analyzed matches? | Season, HomeTeam, AwayTeam, FTR |
| RQ2 — Which teams have strongest attacking performance based on goals, shots, and shots on target? | HomeTeam, AwayTeam, FTHG, FTAG, HS, AS, HST, AST |
| RQ3 — How is half-time result associated with final result? | HTHG, HTAG, HTR, FTHG, FTAG, FTR |
| RQ4 — How are total goals distributed? | FTHG, FTAG; derived total_goals |
| RQ5 — How are shots, shots on target, and corners associated with outcomes? | HS, AS, HST, AST, HC, AC, FTR; optional HY, AY, HR, AR |

These questions ask about association and patterns, not causal effects.
